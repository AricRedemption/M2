## 社区蒸馏门协议(AMM-008,轮 9 起)

**检索前必填问表**(四栏,随条目入账;缺任一栏=不对齐,须补齐再检):

| 栏 | 内容 | 反例(不对齐) |
|---|---|---|
| 现状 | 体系/实验此刻在哪(一句话) | 复述整轮叙事(太长) |
| 问题 | 卡住的那件事,**翻译成社区语言** | "MT-LNN d16 不收敛"(项目黑话,检不到) |
| 目标 | 拿到什么算"获取到了"(可判定) | "看看别人怎么做"(不可判定) |
| 检索颗粒度 | 关键词面=别人也遇到过的那个问题层级 | 太抽象("AI 怎么推理")/太项目特定("γ配额") |

- **触发**:①例行=每 ~10 产出轮;②现象驱动=同一 current_variable 连续
  ≥2 轮 NOT-Achieved 无进展,或判读出现需外部先验的分叉;③用户点名。
- **纪律**:≥2 独立来源交叉,单源=待验证标记;入账判定四分法(已具备/
  缺口⇒AMM 候选/条件触发/拒);**拒绝也留痕**防重查;采纳走 AMENDMENTS。
- **零定时**:检索只发生在轮内,禁后台监听(AMM-003 约束)。

## AMM-006 候选:经验检索-精炼闭环(ExpeL 式)— ADOPTED(轮 10,并入 AMM-009:读回环=GOAL-PROMPT v4.0 步骤 1;"每 8 产出轮精炼轮"暂缓,账本 ≥10 条再议)

- ①开场三查第 1 查并读 **DISTILL 尾部最近 2 条**(机械提示:goal_check
  --audit 末行输出尾条标题);目的=写下来的经验必须被下一轮读到。
- ②每 **8 个产出轮**一次"洞察精炼轮":读全账本,追加一条精炼条目
  (supersede 指针标注被吸收的旧条目——追加,不改历史),可复用配方
  打 `配方` 标签(AWM 精神);精炼轮计半例外轮(防用精炼规避例外轮
  上限)。
- ③拒绝项:不做推理时自动检索(RAG 化)——账本个位数条目时人工可读,
  机械化收益<复杂度(精简工具偏好;等账本 >50 条再议)。
- 采纳时承重句 19→20("经验检索"),goal_check/测试同提交。

## 社区获取条目(问表驱动,AMM-008)

### #1 Dream-RSI 深挖(轮 9,2026-10-01)
- **问表**:现状=蒸馏门/HORIZON 已机制化,检索仍手工一次性;问题=昂贵
  训练与判读耦合,判读问题常被"再跑一次"回答;目标=拿到"重放自有
  历史代替真实重跑"的可迁移启发式;检索颗粒度=replay own experience
  self-improvement agent frozen world model 2026。
- **来源**:[arXiv 2609.14858](https://arxiv.org/abs/2609.14858)(2+ 独立
  来源交叉:HF Daily Papers/HN 讨论/官方代码库)。
- **启发式(采纳,不改机制只改做法)**:
  ①**改进发生在编排层而非权重层**——Dream-RSI 权重冻结、探索策略可
  编程=对 M2"循环体系即编排层"路线的直接实证背书;
  ②**frozen replay worlds**:历史轨迹=可廉价重放的资产——M2 对应物=
  partial jsonl/mid_eval checkpoint/死亡腿 log;**判读问题的第一答案
  应在已冻结的落盘数据上找**,新训练腿是最后手段(18.5h 死亡腿 log
  免费回答了 chance 平台期问题=已验证的先例);
  ③**dream=在冻结历史上演练候选方案再上岗**——M2 对应物=新判据口径/
  新分析管线先在已落盘 jsonl 上 dry-run(管道自洽性,非判读!),再
  决定是否发新腿;mid_eval_discipline(禁中途判)不破:dry-run 验证
  的是**管道**,不产出结论;
  ④**162x 的本质=分离探索成本与评估成本**——M2 的 mid_eval+partial
  台账已是此方向,登记为设计原则:可见性 checkpoint 是训练腿标配。
- **判定**:启发式 ①-④ 采纳(做法层);重放基建(确定性重放器)=
  条件触发,进入 agent 训练线再立项。

### #2 pointer-chase 可达性社区先验(轮 9,2026-10-01;直接服务 current_variable)
- **问表**:现状=P0-C′ phase_1 对照(transformer 30k 步)全 chance,
  phase_3 复核在途;问题=多跳 pointer chase 对 ~250K 参数 transformer
  是否结构性不可达,30k 步离 grokking 视界多远(社区语言:multi-hop
  pointer chasing small transformer chance level grokking);目标=拿到
  文献量级参照,校准 budget_wall 判读与"加预算 vs 换任务"的下一预
  注册;检索颗粒度=pointer chasing / multi-hop composition / grokking
  implicit reasoning。
- **来源**:[Barriers to Discrete Reasoning with Transformers(EACL 2026)]
  (https://aclanthology.org/2026.eacl-long.87.pdf) + [Grokked Transformers
  are Implicit Reasoners(arXiv 2405.15071,NeurIPS 2024)]
  (https://arxiv.org/html/2405.15071v3)(2 独立来源)。
- **先验**:①transformer 每层≈1 跳组合,固定层数小模型的多跳指针追踪
  是**已知结构性障碍**(Ponzio 1999 起的经典难度);②隐式多跳推理
  **仅经 grokking 可达**(远超过拟合点的长期训练后),机制=induction
  类结构长成;③社区 grokking 案例(chance 平台期→突变)在组合任务
  上训练量常到 10^5-10^6 步量级。
- **对 M2 判读链的输入(不改判据,只喂下一预注册)**:phase_3 若仍
  chance ⇒ budget_wall 诊断成立且**有文献支撑**(结构性障碍+grokking
  视界≫30k 步);"加预算"若要走,量级参照=10^5-10^6 步而非 2-3×;
  或按 v1 scope_note 走"换任务另立预注册"。此输入登记进 P0-C′
  verdict 诊断的 budget_wall 条目作外部参照。
- **判定**:已获取(2 源交叉,目标达成);无机制改动。
