## 锚定

- **0** = 弱基线:循环启动前状态(2026-09-27 前,HANDOFF 散文接续、
  门禁靠自觉、单 seed 事故后纪律靠人记)。
- **0.6** = 前沿参照:预注册+多 seed+循环门禁全绿成为无例外常态的
  连续 10 个产出心跳(目标参照,首次达成后回填实测)。
- **1.0** = 上界:理论最优(每轮都是机制级结论且零坑复发、全溯源、
  T=1.0)。
